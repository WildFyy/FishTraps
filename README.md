# Fish Traps  

Fish Traps is a Minecraft datapack that adds craftable fish traps to automate fishing.  

## Crafting fish traps  

You can craft a fish trap by using the following ingredient with a crafting table or a crafter.  
- 6 Sticks / Bamboo (combinations of both work)  
- 2 Strings  
- 1 Rotten flesh / Spider eye / Fermented spider eye  

**Shape**  

|      |            |      |
|:----:|:----------:|:----:|
|Stick |Stick       |Stick |
|String|Rotten flesh|String|
|Stick |Stick       |Stick |

## Using fish traps  

Place the armor stand in **water**.  
Wait and an item (obtainable from fishing) will be dropped. You will see bubble particles on the trap and hear a splash sound if you are close enough. More items will be dropped every **90 seconds**.  
The armor stand's feet have to be in water or a waterlogged block to work.  
The item collection can be automated by placing the fish trap on a waterlogged non-full block (such as a slab) above a hopper.  

## Removing fish traps  

Fish traps can be killed like regular armor stands.  
The fish trap won't drop itself, it will drop a regular armor stand instead (if the game rules allow it).  

## Uninstalling  

You can remove the datapack safely. Existing items and fish traps will remain but they will no longer work. If you reisntall the datapack, they will work again.  
You can kill all the placed fish traps using this command :  
```/kill @e[type=minecraft:armor_stand,tag=fish_trap]```
